# XboxCloudViewer
XboxCloudViewer is an Android application designed to bring Xbox gaming to dual-screen devices, allowing users to stream their Xbox games and consoles directly from a dedicated app.
Built with Kotlin, XboxCloudViewer aims to provide a seamless Xbox streaming experience, with a particular focus on handheld devices featuring two screens.
The application is currently being developed and tested on the AYN Thor.

## Features
- Xbox Cloud Gaming — Stream supported Xbox games directly from the cloud.
- Xbox Remote Play — Stream games directly from your Xbox console.
- Dual-Screen Support — Designed with dual-screen Android devices in mind.
- Handheld Experience — Optimized for portable gaming devices.

## Device Compatibility
XboxCloudViewer is designed primarily for Android handhelds featuring dual-screen configurations.

| Device | Status |
|-----------|-----------|
